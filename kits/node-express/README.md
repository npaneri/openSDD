# Node.js Express Kit

## Description
A complete SpecSet starter for Node.js + Express.js projects with Zod validation and vitest testing.

## Tech Stack
- **Framework**: Express.js
- **Language**: JavaScript/TypeScript
- **Build**: npm
- **Lint**: biomes
- **Testing**: vitest
- **Backend**: PostgreSQL

## Installation
```bash
opensdd kit install node-express
# or: npx opensdd kit install node-express
```

## Generated SpecSet Structure
After running the install command, your project will have:
- `specs/<project-name>/mission.md` — API description
- `specs/<project-name>/tech-stack.md` — Express + Zod pre-configured
- `specs/<project-name>/roadmap.md` — Phase 1 defined
- `specs/<project-name>/2026-11-02-1-core-routes/requirements.md` — Core route requirements
- `specs/<project-name>/2026-11-02-1-core-routes/plan.md` — Phase 1 task groups
- `specs/<project-name>/2026-11-02-1-core-routes/validation.md` — Phase 1 validation

## Customization
- Edit `tech-stack.md` to match your exact stack
- Modify Phase 1 task groups in `plan.md` for your features
- Add new phases following the OpenSDD discipline in `sdd/`

## Kit Version
0.1.0 — Initial release. Follow SpecSet-1 discipline for phase management.
