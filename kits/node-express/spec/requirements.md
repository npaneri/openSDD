# Node.js API — Phase 1: Core Routes

## Scope
This phase defines the requirements for core API routes with Zod validation and Express.js.

## In Scope
- Core API routes (GET /health, POST /users)
- Zod schema validation for request bodies
- Express.js router setup

## Out of Scope
- Authentication middleware (Phase 2)
- OpenAPI generation (Phase 3)

## Decisions
| Decision | Choice | Rationale |
|---|---|---|
| Route pattern | `/api/v1/:resource` | Consistent with REST conventions |
| Validation | Zod schemas | Type-safe, runtime validation |
| Error format | `{ code, message }` | Simple, predictable |

## Context
- Generated by OpenSDD kit: node-express
- Framework: Express.js
- Validation library: Zod

## Dependencies
- None. First phase.

## Risks
| Risk | Mitigation |
|---|---|
| Route overlap | Define explicit path prefixes |
| Schema drift | Keep Zod schemas in dedicated directory |
