# Python API — Phase 1: Core Endpoints

## Scope
This phase defines the requirements for core API endpoints with Pydantic validation and FastAPI.

## In Scope
- Core API endpoints (GET /health, POST /users)
- Pydantic model validation for request bodies
- FastAPI router setup

## Out of Scope
- Authentication middleware (Phase 2)
- OpenAPI generation (Phase 3)

## Decisions
| Decision | Choice | Rationale |
|---|---|---|
| Route pattern | `/api/v1/:resource` | Consistent with REST conventions |
| Validation | Pydantic models | Type-safe, runtime validation |
| Error format | `{ "detail": [...] }` | FastAPI standard |

## Context
- Generated by OpenSDD kit: python-fastapi
- Framework: FastAPI
- Validation library: Pydantic

## Dependencies
- None. First phase.
